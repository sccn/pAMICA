# Changelog

pamica's changelog is [`docs/changelog.md`](docs/changelog.md),
published at <https://eeglab.org/pAMICA/changelog/>.
It lists the user-visible changes in every release since 0.1.0, newest first,
with the changes merged since the last release under **Unreleased**.
Each release's section is also its note on the
[GitHub releases page](https://github.com/sccn/pAMICA/releases).
